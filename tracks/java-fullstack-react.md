# Senior Full Stack Java Developer (React.js + Spring Boot 3) Track

## Who This Is For
Senior full-stack developers delivering modern, accessible React/Next.js frontends powered by robust Java 21 Spring Boot REST/GraphQL microservices.

## Expected Skills
- Java 21/17, Spring Boot 3, RESTful APIs, Spring Security (OAuth2/OIDC, JWT)
- React.js 18+, TypeScript, Next.js, Tailwind CSS, TanStack Query / React Query
- State management, optimistic UI updates, WebSocket / SSE real-time notifications
- PostgreSQL, Redis caching, Docker, CI/CD pipeline automation
- 1,111+ LeetCode algorithmic problem-solving mastery

## Interview Focus Areas
1. End-to-end feature delivery: from UI component design to database schema tuning
2. Contract-first REST/GraphQL API integration with strict TypeScript typing
3. Optimistic UI rendering and real-time state synchronization via SSE/WebSockets
4. Web performance optimization: bundle size reduction, SSR/SSG tradeoffs, and caching

## Key Production Interview Questions
- How do you structure an end-to-end full-stack feature from a Next.js frontend to a Spring Boot 3 backend with type-safe contracts?
- How do you implement optimistic UI updates and rollback mechanisms in React when a Spring Boot backend mutation fails?
- Walk me through your authentication flow using JWT, HttpOnly cookies, and Spring Security 6.
- How do you optimize initial page load performance in a React application backed by a high-throughput Java API?

## Seniority Expectations
At Senior & Staff level for this track, interviewers expect:
- Deep empirical command of systems you designed, with exact metrics and latency breakdowns.
- Clear articulation of trade-offs (e.g., consistency vs latency, memory footprint vs CPU overhead).
- Proactive identification of production failure modes and disaster recovery runbooks.
- Strong cross-functional technical leadership and setting architectural standards.

# Senior Full Stack AI Web Developer Track

## Who This Is For
Engineers building rich, interactive AI-powered web applications with streaming UX, tool call rendering, real-time collaboration, and scalable APIs.

## Expected Skills
- React.js, Next.js (App Router, Server Components, Server Actions), TypeScript
- FastAPI, asyncio, Server-Sent Events (SSE) streaming, WebSockets
- Vercel AI SDK, LangChain.js, streaming UI component rendering
- Tailwind CSS, Radix UI, responsive design, dark mode, accessibility
- PostgreSQL, Redis, Docker, 1,111+ LeetCode problem mastery

## Interview Focus Areas
1. Real-time streaming text and generative UI component rendering
2. Optimizing frontend rendering performance during high-frequency token streams
3. Building intuitive chat interfaces, STAR story banks, and interactive dashboards
4. End-to-end security: CSRF, XSS, rate limiting, and API key management

## Key Production Interview Questions
- How do you implement resilient Server-Sent Events (SSE) token streaming in React without causing excess re-renders or UI jank?
- Walk me through how you render dynamic generative UI components and tool call artifacts as an AI generates content.
- How do you manage client-side state for multi-turn conversational agents with branching and retry capabilities?
- How do you secure browser-based AI applications to prevent API key exposure and malicious prompt injection via user input?

## Seniority Expectations
At Senior & Staff level for this track, interviewers expect:
- Deep empirical command of systems you designed, with exact metrics and latency breakdowns.
- Clear articulation of trade-offs (e.g., consistency vs latency, memory footprint vs CPU overhead).
- Proactive identification of production failure modes and disaster recovery runbooks.
- Strong cross-functional technical leadership and setting architectural standards.
